# Fallback: источники недоступны скрипту

`status.json` после `digest_collect.py` показывает, что произошло с каждым источником (`reason` — источник не дал ничего; `partial` — часть запросов не прошла). Ситуации:

| reason | Что это | Что делать |
|---|---|---|
| `proxy_denied` | Сетевая политика среды режет исходящие соединения скрипта (в claude.ai: Settings → Capabilities → «Allow network egress» выключен; в Enterprise — политика организации). Скрипт не виноват. | Сначала режим B: `scripts/fetch_run.py --repo <owner>/<repo>` (сбор на GitHub Actions, см. `deploy/README.md`) — GitHub из песочницы доступен. Если прогона извне нет — одной строкой сказать пользователю, что egress закрыт, и идти в WebFetch-режим для того, что он покрывает; остальное — "Not verified". |
| `cloudflare` | Сайт (обычно Nomoplatform) показал бот-проверку. | WebFetch-режим только для этого источника; данные остальных валидны. |
| `ssl_error` | mof.gov.cy отдаёт сертификат без промежуточного CA (подтверждено на GitHub Actions, 21.09.2026). | Сначала достроить цепочку без отключения проверки: `python3 scripts/fix_chain.py www.mof.gov.cy --out ~/digest_out/ca-bundle.pem` и `export REQUESTS_CA_BUNDLE=~/digest_out/ca-bundle.pem` (в workflow это отдельный шаг). Если не удалось — перезапустить с `--insecure-hosts www.mof.gov.cy`: обход проверки только для этого хоста, по явному флагу, с пометкой в Verification; при `proxy_denied` не поможет. |
| `http_error` / `timeout` / `connection` | Сайт лежит или изменился. | Повторить через несколько минут; если стабильно — WebFetch для источника, пометка в «Проверка». |
| `items=0` при ok, вне парламентского перерыва | Изменилась вёрстка (PARSE-EMPTY). | Открыть страницу WebFetch'ем, сверить с `sources.md`, починить модуль; в дайджест — «источник проверен вручную». |
| `offline_miss` (в `partial`) | Прогон шёл из кэша (`--offline`, тесты) и часть URL в кэше не было. | В боевом прогоне не встречается. Если запросы вне окна (старые PDF CyLaw) — покрытие не задето, одна фраза в Verification. |

**Режим B (прогон получен через `fetch_run.py`)**: ничего не дозапрашивать — прогон уже сделан там, где была сеть. `reason`/`partial` в его `status.json` только раскрываются в дайджесте ("Not verified: …" / фраза в Verification); WebFetch добирать только Nomoplatform при `cloudflare`, и только если фетчер доступен.

Никаких обходов: ни бот-защиты, ни TLS без флага. Если источник недоступен и скрипту, и фетчеру — он "Not verified", и дайджест говорит это прямо (в шапке, в секции и в блоке Verification).

## Что WebFetch-режим покрывает, а что нет

Проверено на практике (сентябрь 2026):

| Источник | WebFetch | Замечание |
|---|---|---|
| Επίσημη Εφημερίδα (mof.gov.cy) | **нет** — фетчер падает на TLS уже при чтении robots.txt | Сам сайт Ε.Ε. не нужен: законы и Κ.Δ.Π. недели берутся из индексов CyLII/CyLaw (ниже). В Verification — "Gazette site not reached; laws and Κ.Δ.Π. taken from the CyLaw/CyLII indexes (same-day for Κ.Δ.Π., a few days' lag for laws)". |
| CyLII (cylii.org) — UTF-8 списки | да | `/cy/legis/kdp/arith`: каждая строка = номер, название, `Αρ.` выпуска, страница, дата → Κ.Δ.Π. недели без PDF приложения. `/cy/legis/arith`: законы с названиями (читаемыми, в отличие от cp1253 на cylaw.org). `/updates?date=` — что добавлено за день. Просмотрщик PDF на cylii отдаёт 404 — тексты брать с cylaw.org. |
| gov.cy (все ведомства портала) | **нет** — 403 и на `wp-json`, и на HTML | Сообщения Τμήμα Φορολογίας, Κτηματολόγιο, миграции, соцстрахования не видны → "Not verified". |

## Порядок и бюджет (≈40 вызовов)

1. CyLII `/cy/legis/arith` → последние 12 номеров каждой части с названиями (1 вызов). Затем PDF с cylaw.org по номерам сверху вниз: дата из шапки `Αριθμός NNNN <день недели>, <число> <месяц> <год>`; остановиться после **двух подряд** PDF с датой раньше окна или на 404 у следующего номера (обычно 3–6 вызовов). Из PDF — длинное название, статьи 2–3, вступление в силу.
2. CyLII `/cy/legis/kdp/arith` (1 вызов, просить только строки с датой в окне или с `Αρ.` выпусков недели) → отобрать по практикам → PDF с cylaw.org `/KDP/data/<год>_1_<n>.pdf` только для отобранных (≤6 вызовов): норма и вступление в силу. Дата акта = дата выпуска `Αρ.` (опечатки в отдельных строках игнорировать).
3. Nomoplatform `bills?modified_after=<начало окна>&per_page=25&_fields=id,date,modified,link,title,bill-status,thematic-unit` (1–2 вызова) → отобрать по практикам (`relevance.md`) → страницы отобранных законопроектов, не больше 8: **позиция входит, только если в хронологии есть дата в окне**; `modified` в окне без события — не событие. Σκοπός цитировать со страницы.
4. Nomoplatform `posts?after=…&before=…&categories=488` (1 вызов) — Αποφάσεις Ολομέλειας; при наличии — текст поста (1 вызов).
5. Έφορος Εταιρειών лента (1) + страницы сообщений в окне (≤3).
6. ΚΤΚ лента (1) + страницы регуляторных сообщений в окне (≤3); статистику и заявления не открывать.
7. Если бюджет остался — `parliament.cy` (Ημερήσια Διάταξη Ολομέλειας) для перекрёстной проверки голосований.

Каждую позицию заносить по `digest-format.md` (по-английски); цитировать только то, что фетчер вернул дословно, и только из документов, а не из индексов. Что не подтверждено — не ставить, а перечислить в блоке Verification.

## Юрисдикция при ручном поиске

WebSearch по греческим запросам возвращает вперемешку материалы парламента Греции (hellenicparliament.gr, партии ΝΔ/ΠΑΣΟΚ/ΣΥΡΙΖΑ/ΚΚΕ). В скрипте этого нет по построению; в ручном режиме — только `.cy`-домены: parliament.cy, nomoplatform.cy, cylaw.org, gov.cy, mof.gov.cy, centralbank.cy, companies.gov.cy.
