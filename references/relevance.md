# Фильтр релевантности

Машинная копия — `scripts/cylaw_digest/relevance.py`; этот файл объясняет логику и служит чек-листом при ручной проверке раздела E skeleton («отброшено»). Расширять практику = править `relevance.py` (ключи, id тем Nomoplatform) и этот файл одновременно.

## Как считается балл

- **2 (сильная релевантность)** — сильный ключ в названии или в названии темы Nomoplatform, либо id темы из списка `NOMO_TERMS`. Тело (Σκοπός, длинное название, выдержка) смотрится только если название ничего не дало — иначе законопроект о мигрантах, где упомянуты «εταιρείες», получал бы ярлык «корпоративное».
- **1 (слабая)** — только слабые ключи (οικοδομ-, εμπόρ-, εργασ-, επιτόκ-…). В дайджест попадает, но заслуживает проверки.
- **0** — ничего; либо «шум».
- **Шум** (`NOISE`): вакансии, статистика, индексы (любой «Δείκτης …»), периодические выпуски с датой в названии («…: Αύγουστος 2026», «…: 2ο Τρίμηνο 2026», «Ιανουάριος-Αύγουστος 2026»), туристические прибытия, регистрации автомобилей, данные ΚΤΚ по ставкам/NPL («Στοιχεία επιτοκίων…», «Aggregate … data»), bank holiday, тендеры, стипендии, семинары и конференции, поздравления (συγχαρητήρια)/соболезнования, визиты и встречи, бюджеты, технические перерывы, ТВ-обращения. Шум обнуляет даже сильный ключ: «Statistics on loans» — не право. Список пополнен по первому живому прогону (08–21.09.2026); ожидаемые баллы для этих заголовков закреплены тестом `LiveGoldenTests`.
- **Мягкий шум** (`SOFT_NOISE`): заявления и «интервенции» министров и Президента, интервью, заголовки, начинающиеся с «Ο Υπουργός …» или содержащие «κ. Имя Фамилия», отъезды, встречи. Остаётся с баллом 1, только если в названии есть правовой инструмент или существенное действие (νόμος, νομοσχέδιο, διάταγμα, κανονισμός, εγκύκλιος, ψήφιση, παράταση, προθεσμία, σχέδιο, directive, circular…). «Ο Υπουργός αναχωρεί για τη Βιέννη» — 0; «Δήλωση του Υπουργού για τον περί Φορολογίας Νόμο» — 1; «Δήλωση του Υπουργού … για την παράταση της μείωσης του Ειδικού Φόρου Κατανάλωσης» — 1. Забастовки (απεργία) из слабых ключей убраны: это оперативные новости, не право.
- Сообщения Έφορος Εταιρειών — всегда 2 (источник целиком по практике).
- Законы Παρ. Ι(Ι) с баллом 0 не пропадают: попадают в раздел 4 «Прочие законы недели» одной строкой.

## Ручная проверка раздела E

Раздел E skeleton — всё отброшенное, по источникам. Перед выпуском дайджеста пройти глазами: если там оказалось что-то по практике (новый термин, английский заголовок ΚΤΚ, нетипичное название Κ.Δ.Π.) — включить в дайджест вручную и добавить ключ в `relevance.py`. Это единственный способ, которым фильтр учится.
